# EPSILON Independent Review Log

Status: `Open ledger · no independent review claimed yet`

This ledger records substantive external challenges to EPSILON and what happened next. It exists to preserve criticism, decisions, and product changes—not to manufacture endorsements.

## Counting rules

A response counts as an independent challenge only when:

1. a real person submits it through the [EPSILON Falsification Challenge](https://github.com/DresdenGman/EPSILON-trading-simulator/discussions/8);
2. it identifies a specific assumption, evidence gap, interpretation risk, or product weakness;
3. the reviewer is not the project author or an automated account;
4. the original response remains publicly linkable, unless the reviewer requests privacy;
5. permission is recorded before quoting the reviewer by name.

Praise, Stars, impressions, anonymous claims without evidence, and duplicate responses do not become separate independent reviews.

## Public disposition

| Status | Meaning |
|---|---|
| `ACCEPTED` | A real weakness was identified and a documented change follows. |
| `EXPERIMENT QUEUED` | The objection requires a new test, data source, or protocol. |
| `NOT ACCEPTED` | The objection does not apply; the reason remains public. |
| `DUPLICATE` | It reinforces an existing challenge and links to that record. |

## Integrity rules

- Never purchase or coordinate Stars, votes, comments, reviews, or traffic.
- Never count a private compliment as an independent review.
- Never quote a reviewer by name without permission.
- Never turn controlled synthetic evidence into a historical validation claim.
- Never delete an unfavorable challenge because it weakens the project narrative.
- Correct errors publicly and preserve the correction record.
