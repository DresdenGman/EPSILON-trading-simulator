## Current direction

The next step is a small public question-and-review pilot, supported by the [Assumption Clinic kit](community/ASSUMPTION_CLINIC.md). Planned questions, completed runs, external reviews, feedback-led changes, and confirmed reuse must be recorded separately. Publication of a kit does not mean a session has been held.

## Record boundaries

- Commit dates document source events, not release dates, user counts, or continuous daily work.
- The competition award predates the current instrument; it does not validate later versions or investment performance.
- GitHub attention, website signals, completed historical runs, and independently reproduced results are different categories.
- Daily automated metrics snapshots are not listed as new product milestones.
- Other projects' contacts, pilot results, and recognition do not belong in this timeline.
